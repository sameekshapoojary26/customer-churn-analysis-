# Customer Churn Analysis

## Project Description
This project analyzes customer data to identify patterns behind subscription cancellations.

## Objectives
- Calculate Customer Churn Rate.
- Calculate Customer Lifetime Value (CLV).
- Calculate Monthly Recurring Revenue (MRR) Loss.
- Analyze churn by contract type, tenure and payment method.
- Generate data visualization charts.
- Provide business recommendations.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Files
- churn_analysis.py

## Expected Outcome
Identify customer churn patterns and suggest strategies to improve customer retention.
